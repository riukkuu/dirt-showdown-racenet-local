# Changelog

## [0.1.0] — 2026-11-23

Первый публичный релиз.

### Добавлено

- Установщик `Install.cmd` / `Install.ps1`: автоопределение папки Steam-игры,
  резервные копии `.racenet-original.bak`, подмена встроенного сертификата,
  запись в `hosts`, установка корневого сертификата в `CurrentUser`, ярлыки,
  проверка `http://127.0.0.1/health`, удаление в один клик.
- Два режима: локальный сервер и подключение к серверу друга (Radmin VPN / LAN)
  с автоматической загрузкой сертификата хоста.
- Режим «Разрешить друзей»: `ListenAnyIp` + правило Windows Firewall.
- Self-contained сервер (win-x64, .NET 10), SQLite, без установки рантайма.
- Скрипт сборки релиза без git: патчи + проверка SHA256 + упаковка zip.

### Изменено относительно upstream

- `EgoNetChallengePayloads.cs`
  - `MaxFriendsReturnedToShowdown`: 64 → 256 (друзья с индексом > 64 снова видны).
  - Убран лимит в 20 активных челленджей.
  - `CreateSyntheticFriend`: для друга без записанного челленджа подставляется
    захваченный челлендж из каталога — можно играть и отправлять челленджи без
    второго игрока.
- `RaceNetResponder.cs`
  - `BuildLoginResponse` возвращает `PrincipalId si64` — игра больше не висит на
    «SIGNING INTO RACENET».
  - Ответы Challenge всегда `text/html` + `Cache-Control: private, s-maxage=0`
    (как у настоящего IIS).
  - `IssueChallenge` возвращает `GhostSlotID si64`.
  - Fallback-определение игры: `dirt-showdown`.
- Релизная конфигурация: SQLite (`data/egonet-revival.db`), без захвата запросов,
  прослушивание только localhost по умолчанию.
- Сборка явно закрепляет `System.Security.Cryptography.Pkcs` 10.0.15 вместо
  транзитивной 9.0.11 (CVE-2026-70162, CVE-2026-84008). Сервер не разбирает
  недоверенный CMS/PKCS#7, но так релиз собирается без NU1902/NU1903.

### Известные ограничения

- Нужен хотя бы один друг в Steam: список друзей приходит от клиента.
- Достижения Fanbase (10/20/30 онлайн) не гарантируются — зависит от того,
  начисляет ли клиент XP за челленджи.
- `Beat it!` и `Running the Show` требуют проверки на разных аккаунтах.
- Порт 80/443 должен быть свободен; сервер и игра должны работать одновременно.
