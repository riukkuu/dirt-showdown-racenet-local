# Игра с другом (Radmin VPN / LAN)

Сервер один — у хоста. Друг не запускает свой сервер: он подключается к вашему.
Оба клиента видят общие челленджи и могут обмениваться ими.

```
Хост:  игра  ──► 127.0.0.1:443  ──►  RaceNet Local server
                                        ▲
Друг:  игра  ──► IP хоста:443  ────────┘   (Radmin VPN / LAN)
```

## Хост

1. Установите мод как обычно, но включите галочку
   **«Разрешить подключение друзей (Radmin VPN / LAN)»**
   (или запустите `Install.ps1 -Silent -AllowFriends`).
   Это:
   - ставит `ListenAnyIp: true` в `appsettings.json` (сервер слушает все
     интерфейсы, а не только localhost);
   - добавляет правило Windows Firewall `RaceNet Local (TCP 80,443)`
     для профилей Private/Domain.
2. Установите [Radmin VPN](https://www.radmin-vpn.com/) (или ZeroTier / Hamachi),
   создайте сеть и пригласите друга — либо используйте один LAN/Wi-Fi.
3. Узнайте свой IP в этой сети:

   ```powershell
   ipconfig
   # Radmin VPN: адаптер "Radmin VPN", IPv4 26.x.x.x
   # LAN: IPv4 192.168.x.x
   ```

4. Запустите сервер ярлыком **«DiRT Showdown — RaceNet»**. Окно сервера можно
   свернуть, но не закрывать.
5. Проверьте, что сервер доступен извне:

   ```powershell
   curl http://<ваш IP>:80/health
   ```

   Если изнутри отвечает, а снаружи нет — firewall или сеть Radmin.

## Друг

1. Скачайте тот же zip. Установщик → режим
   **«Подключиться к серверу друга»**, IP — адрес хоста из шага 3.
   Или:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install.ps1 -Mode Friend -Server 203.0.113.10
   ```

2. Установщик скачает корневой сертификат прямо с сервера хоста
   (`http://<IP>/racenet-root-ca.cer`), пропатчит свои `showdown*.exe`, поставит
   сертификат и запишет `hosts` на IP хоста. Сервер другу не нужен.
3. **Сервер хоста должен быть запущен во время установки у друга** — иначе
   скачать сертификат не получится.
4. Запускайте игру (ярлык или Steam) и входите в RaceNet.

## Важно

- Сертификат у друга должен быть **тот же**, что у хоста. Он скачивается
  автоматически. Если хост удалил `%LOCALAPPDATA%\RaceNetLocal\server\certs`
  и сертификаты перегенерировались — друг должен заново запустить установщик
  в режиме Friend.
- Порт хоста по умолчанию **80** (сертификат) и **443** (игра). Если у хоста
  занят 80, установка друга не сможет скачать сертификат — освободите порт.
- Оба игрока должны быть в одной виртуальной сети; NAT-проброс портов для
  Radmin VPN не нужен.
- Челленджи асинхронные: не обязательно играть одновременно. Результаты
  сохраняются в базе хоста (`server\data\egonet-revival.db`).
- IP хоста в Radmin может меняться после перезапуска сети. Если друг перестал
  подключаться — проверьте IP и при необходимости повторите установку с новым
  адресом (или поправьте блок `# --- RaceNetLocal ---` в `hosts` вручную).

## Диагностика

На хосте:

```powershell
# слушает ли сервер все интерфейсы
Get-NetTCPConnection -State Listen -LocalPort 443

# правило firewall
Get-NetFirewallRule -DisplayName "RaceNet Local (TCP 80,443)"

# доступность с другого ПК
curl http://203.0.113.10/health
```

Если `curl` снаружи не работает:

- проверьте, что в `appsettings.json` стоит `"ListenAnyIp": true`;
- разрешите порты 80 и 443 для сети Radmin в брандмауэре;
- проверьте, что Radmin VPN не блокирует обмен между участниками.

## Ограничения

- Это не полноценный онлайн-мультиплеер: гонки вдвоём в лобби мод не включает.
- Один сервер = один общий «мир» челленджей. Две независимые компании друзей
  лучше не смешивать на одном хосте.
- Данные хранятся в SQLite у хоста. Резервная копия —
  `%LOCALAPPDATA%\RaceNetLocal\server\data\egonet-revival.db`.
