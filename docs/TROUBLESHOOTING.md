# Решение проблем

## Установщик

### Windows SmartScreen / «Windows защитила ваш компьютер»

Файл `Install.cmd` из архива помечен как скачанный. Нажмите **«Подробнее» →
«Выполнить в любом случае»**. Это обычный cmd-скрипт, который запускает
`powershell -ExecutionPolicy Bypass -File Install.ps1`.

### «Не найдена папка DiRT Showdown»

- Игра должна быть **Steam-версией** (appid 201700), не пиратской сборкой.
- Укажите папку вручную: та, где лежит `showdown.exe`, обычно
  `...\steamapps\common\DiRT Showdown`.
- Если игра в другой библиотеке Steam, установщик читает
  `steamapps\libraryfolders.vdf`; при нестандартном расположении выберите папку
  через «Обзор...».

### «Не удалось получить права администратора»

Установщик просит UAC для правки `hosts`. Если политика запрещает повышение —
запустите `Install.cmd` из-под администратора вручную (правый клик →
«Запуск от имени администратора»).

### Антивирус ругается на `showdown.exe`

Патченный exe отличается от исходного на 1003 байта (сертификат) — эвристика
иногда реагирует. Файл можно восстановить: Steam → «Проверить целостность»,
либо `.racenet-original.bak`.

## Игра не входит в RaceNet

### Висит «SIGNING INTO RACENET»

1. Сервер запущен? Откройте в браузере `http://127.0.0.1/health` — должен быть
   JSON `{"ok":true,...}`.
2. `hosts` указывает на `127.0.0.1`?
   ```
   C:\Windows\System32\drivers\etc\hosts
   ```
   Блок `# --- RaceNetLocal begin --- ... end ---`.
3. Exe пропатчен? Запустите установщик заново: он напишет «уже пропатчен» или
   перепатчит.
4. Порт 443 занят другим процессом — см. ниже.
5. Перезапустите сервер и игру (клиент кэширует неудачный логин).

### Ошибка сертификата / соединение сбрасывается

Сертификат в exe не совпадает с сертификатом сервера. Обычно после:

- удаления `%LOCALAPPDATA%\RaceNetLocal\server\certs` (сервер перегенерировал
  сертификат, exe остался со старым);
- обновления игры через Steam;
- ручной правки `hosts` на другой сервер.

Решение: запустить установщик заново (локальный режим или режим друга).

## Пустые Challenges

- **Нет друзей в Steam.** Клиент присылает список друзей; без друзей серверу
  некого показывать. Добавьте хотя бы одного друга (лучше с DiRT Showdown) и
  перезапустите игру.
- Друг есть, но игра не перезапускалась после установки — закройте и откройте.
- Сервер смотрит в другую базу: удалите `server\data\egonet-revival.db` (потеря
  локальных челленджей) и перезапустите.

## Порты 80/443 заняты

Симптом: установщик пишет «Сервер не отвечает на http://127.0.0.1/health».

```powershell
Get-NetTCPConnection -State Listen -LocalPort 80,443 |
  Select-Object LocalAddress,LocalPort,OwningProcess,
    @{n='Process';e={(Get-Process -Id $_.OwningProcess).ProcessName}}
```

Типичные виновники:

| Процесс | Что делать |
|---|---|
| `w3wp`, `System` (IIS) | остановить сайт/службу W3SVC: `Stop-Service W3SVC` |
| `vmware-hostd` | остановить службу VMware Host Agent |
| `Skype` | отключить использование портов 80/443 в настройках |
| `Docker Desktop` | остановить контейнеры/прокси |
| другой экземпляр сервера | `taskkill /IM RaceNetShowdown.Server.exe /F` |

Освободите порты и нажмите **Установить** повторно (или запустите сервер вручную
из `%LOCALAPPDATA%\RaceNetLocal\server`).

## Достижения не появляются

- Steam в сети? Оверлей включён?
- Достижение уже открыто — Steam не уведомляет повторно.
- Для челленджей результат должен быть **засчитан**: смотрите лог сервера,
  строки `IssueChallenge` / `SubmitChallengeResult` с кодом `200`.
- `No Turning Back` выдаётся после **отправки** челленджа, а не после принятия.
- Перезапустите Steam (кэш достижений).
- Подробнее: [ACHIEVEMENTS.md](ACHIEVEMENTS.md).

## Друг не подключается

- У хоста включён режим «Разрешить друзей» (`ListenAnyIp: true`)?
- Правило firewall `RaceNet Local (TCP 80,443)` существует и включено?
- Друг и хост в одной сети Radmin VPN / LAN? `ping <IP хоста>` работает?
- У друга в `hosts` правильный IP? При смене IP хоста — переустановка.
- Хост должен быть запущен в момент установки у друга (скачивание сертификата).

## Сервер падает или не стартует

Смотрите:

- окно сервера (оно остаётся открытым/свёрнутым);
- `%LOCALAPPDATA%\RaceNetLocal\server\logs\`;
- `%TEMP%\RaceNetLocal-install.log`.

Частые причины:

- заняты порты 80/443;
- повреждён `appsettings.json` (проверьте JSON-синтаксис);
- сертификаты в `certs` повреждены — удалите папку `certs` и запустите
  `RaceNetShowdown.Server.exe --regenerate-certs`, затем переустановите мод;
- сервер запущен от другого пользователя Windows, чем установщик (ключ
  сертификата лежит в профиле того, кто ставил).

## Несколько учётных записей Windows

Корневой сертификат ставится в профиль пользователя, который запускал установщик.
Если игра запускается под другим пользователем — сертификат в exe всё равно
работает (он в файле), но `hosts` общий. Ключ сервера привязан к профилю:
запускайте сервер под тем же пользователем, что и установку.

## Что приложить к issue

- Версия Windows и сборки игры (Steam → свойства → файлы).
- `%TEMP%\RaceNetLocal-install.log`.
- Последние 50 строк `server\logs\requests.jsonl` (если есть).
- Что именно делали и какой текст ошибки.

Не прикладывайте личные данные: IP Radmin, SteamID, сертификаты.
