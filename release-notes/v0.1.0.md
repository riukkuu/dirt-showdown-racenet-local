## English

A local RaceNet server for DiRT Showdown: challenges, friends and online
achievements without the Codemasters servers. Everything runs on your PC.

### Installation

1. Download `RaceNetLocal-DiRT-Showdown-v0.1.0.zip` and extract it **completely**.
2. Close the game. Run `Install.cmd` and confirm UAC.
3. Click **Install**.
4. Launch the game with the **"DiRT Showdown — RaceNet"** shortcut.

To remove: `Install.cmd` → **Uninstall mod**.

The installer GUI has an **EN / RU** button in the top-right corner; your choice
is remembered.

### What's inside

- `Install.cmd`, `Install.ps1` — installer with GUI and CLI.
- `server/` — self-contained server (win-x64, .NET 10, SQLite).
- `docs/` — installation, achievements, friends, troubleshooting.
- `LICENSE`, `NOTICE.md` — license and upstream status.

### What's new

- Local mode: the game connects to `127.0.0.1`, no second PC needed.
- Synthetic challenges for friends without records — playable solo.
- Fixed RaceNet login (no more endless "SIGNING INTO RACENET").
- Friend list up to 256, no 20-challenge limit.
- Installer: game autodetect, backups, hosts, certificate, shortcuts, health check.
- "Connect to a friend's server" mode (Radmin VPN / LAN) with automatic host
  certificate download.
- Bilingual installer UI: RU / EN toggle.

### Achievements

- **No Turning Back** — verified working.
- **Beat it!** — expected, needs confirmation on a live account.
- **Running the Show** — requires a winning streak (tally +10).
- Fanbase 10/20/30 — not guaranteed: the local server does not emulate online
  races.

Details: `docs/ACHIEVEMENTS.md`.

### Known limitations

- At least one Steam friend is required: the friend list comes from the client.
- Ports 80/443 must be free.
- The server must be running while you play.

### Integrity

SHA256: see `RaceNetLocal-DiRT-Showdown-v0.1.0.zip.sha256`.

### Disclaimer

Unofficial preservation project. Not affiliated with Codemasters, EA or Valve.
No game files are distributed. Use at your own risk.

## Русский

Локальный сервер RaceNet для DiRT Showdown: челленджи, друзья и онлайн-достижения
без серверов Codemasters. Всё работает на вашем ПК.

### Установка

1. Скачайте `RaceNetLocal-DiRT-Showdown-v0.1.0.zip` и распакуйте **целиком**.
2. Закройте игру. Запустите `Install.cmd`, подтвердите UAC.
3. Нажмите **Установить**.
4. Запускайте игру ярлыком **«DiRT Showdown — RaceNet»**.

Удаление: `Install.cmd` → **Удалить мод**.

В интерфейсе установщика есть кнопка **EN / RU** в правом верхнем углу — язык
подписей, кнопок, сообщений и лога переключается, выбор запоминается.

### Что внутри

- `Install.cmd`, `Install.ps1` — установщик с GUI и CLI.
- `server/` — self-contained сервер (win-x64, .NET 10, SQLite).
- `docs/` — установка, ачивки, друзья, решение проблем.
- `LICENSE`, `NOTICE.md` — лицензия и статус upstream.

### Что нового

- Локальный режим: игра ходит на `127.0.0.1`, второй ПК не нужен.
- Синтетические челленджи для друзей без записей — можно играть одному.
- Исправлен вход в RaceNet (не висит «SIGNING INTO RACENET»).
- Список друзей до 256, без лимита в 20 челленджей.
- Установщик: автопоиск игры, бэкапы, hosts, сертификат, ярлыки, health-check.
- Режим «подключиться к серверу друга» (Radmin VPN / LAN) с автоматической
  загрузкой сертификата хоста.
- Двуязычный интерфейс установщика: переключатель RU / EN.

### Достижения

- **No Turning Back** — работает, проверено.
- **Beat it!** — ожидается, требует проверки на живом аккаунте.
- **Running the Show** — требует серии побед (счёт +10).
- Fanbase 10/20/30 — не гарантируется: локальный сервер не эмулирует онлайн-гонки.

Подробно: `docs/ACHIEVEMENTS.md`.

### Известные ограничения

- Нужен хотя бы один друг в Steam: список друзей приходит от клиента.
- Порты 80/443 должны быть свободны.
- Сервер должен работать одновременно с игрой.

### Проверка целостности

SHA256 архива: см. файл `RaceNetLocal-DiRT-Showdown-v0.1.0.zip.sha256`.

### Дисклеймер

Неофициальный проект для сохранения игры. Не связан с Codemasters, EA или Valve.
