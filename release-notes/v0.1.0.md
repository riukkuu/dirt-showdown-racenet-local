# RaceNet Local v0.1.0 — DiRT Showdown

Локальный сервер RaceNet для DiRT Showdown: челленджи, друзья и онлайн-достижения
без серверов Codemasters. Всё работает на вашем ПК.

## Установка

1. Скачайте `RaceNetLocal-DiRT-Showdown-v0.1.0.zip` и распакуйте **целиком**.
2. Закройте игру. Запустите `Install.cmd`, подтвердите UAC.
3. Нажмите **Установить**.
4. Запускайте игру ярлыком **«DiRT Showdown — RaceNet»**.

Удаление: `Install.cmd` → **Удалить мод**.

## Что внутри

- `Install.cmd`, `Install.ps1` — установщик с GUI и CLI.
- `server/` — self-contained сервер (win-x64, .NET 10, SQLite).
- `docs/` — установка, ачивки, друзья, решение проблем.
- `LICENSE`, `NOTICE.md` — лицензия и статус upstream.

## Что нового

- Локальный режим: игра ходит на `127.0.0.1`, второй ПК не нужен.
- Синтетические челленджи для друзей без записей — можно играть одному.
- Исправлен вход в RaceNet (не висит «SIGNING INTO RACENET»).
- Список друзей до 256, без лимита в 20 челленджей.
- Установщик: автопоиск игры, бэкапы, hosts, сертификат, ярлыки, health-check.
- Режим «подключиться к серверу друга» (Radmin VPN / LAN) с автозагрузкой
  сертификата хоста.

## Достижения

- **No Turning Back** — работает.
- **Beat it!** — ожидается, требует проверки на живом аккаунте.
- **Running the Show** — требует серии побед (счёт +10).
- Fanbase 10/20/30 — не гарантируется: локальный сервер не эмулирует онлайн-гонки.

Подробно: `docs/ACHIEVEMENTS.md`.

## Известные ограничения

- Нужен хотя бы один друг в Steam: список друзей приходит от клиента.
- Порты 80/443 должны быть свободны.
- Сервер должен работать одновременно с игрой.

## Проверка целостности

SHA256 архива: см. файл `RaceNetLocal-DiRT-Showdown-v0.1.0.zip.sha256`.
