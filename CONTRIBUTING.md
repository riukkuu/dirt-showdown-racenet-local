# Участие в проекте

Спасибо, что хотите помочь. Проект маленький, поэтому правил немного.

## Сообщить о проблеме

1. Проверьте [решение проблем](docs/TROUBLESHOOTING.md) — половина вопросов
   закрывается там.
2. Откройте issue через шаблон **Bug report**. Чем больше деталей, тем быстрее
   разберёмся.
3. Приложите:
   - версию Windows и сборки игры (Steam → свойства → файлы);
   - `%TEMP%\RaceNetLocal-install.log`;
   - последние 50 строк `%LOCALAPPDATA%\RaceNetLocal\server\logs\requests.jsonl`;
   - что именно делали и какой текст ошибки увидели.

**Не прикладывайте** личные данные: IP в Radmin VPN, SteamID, сертификаты,
скриншоты с ником. Если нужно показать лог — уберите эти строки.

## Предложить исправление

- Правки установщика, документации и скриптов — обычный pull request.
- Патчи к upstream-серверу лежат в `patches/` и привязаны к коммиту
  `9d2c7d6bcc716e10e3327e26c1dbe3a1434d37d2`. Если меняете поведение сервера:
  1. измените файлы, соберите релиз;
  2. снимите новый diff в `patches/`;
  3. обновите ожидаемые SHA256 в `tools/apply-patches.ps1`;
  4. убедитесь, что `tools/build-release.ps1` проходит с нуля.
- Файлы игры, сертификаты и чужие бинарники в репозиторий не принимаются.

## Стиль

- Документация — по-русски, коротко и по делу; английский перевод README
  поддерживаем синхронно.
- Скрипты — Windows PowerShell 5.1 (не только PowerShell 7), без внешних
  зависимостей.
- Коммиты: `установщик: ...`, `docs: ...`, `server: ...`.
